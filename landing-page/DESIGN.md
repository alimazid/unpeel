# Fork feature showcase, iteration 2

Reading this as a product landing page for people supervising local agent work, in the visual language of a technical field guide. ENERGY 2 / RHYTHM 2 / MOTION 1.

## Direction

- Product: Ali Mazid's fork adds file exploration, file operations, Git history, and document previews to the Unpeel Mac workspace.
- Character: concrete, observant, workmanlike.
- World: the native Mac workspace and files its agents produce.
- Moments: actual fork screenshots, especially Explorer status letters and expanded Git commits.
- Signature: keyboard shortcuts in keycaps and numbered feature captions, like a compact field guide.

## Iteration-one audit

- The centered serif headline and generic terminal demo could describe other agent products.
- Uppercase tracked labels and small captions weakened hierarchy.
- The screenshot, copy, and downloads sold upstream features.
- Equal feature columns and an orbit drawing were generic filler.
- The installer installed the original product rather than the fork.

## Decisions and passes

Spacing follows a 4px rhythm, with larger breaks between feature groups. Near-white surfaces let dark app captures lead; blue marks the primary action and echoes selection in the real app. Decorative glyphs and agent logos are removed. IBM Plex Sans carries the technical copy; IBM Plex Mono is limited to shortcuts and status letters. An asymmetric hero introduces the actual workspace, followed by Explorer, Git history, and Markdown captures. Screenshot buttons open the original images in an accessible dialog, and their captions identify the test repositories. Motion is limited to short hover feedback and optional smooth scrolling, disabled for reduced motion.

The copy describes local Mac limitations and read-only history. No performance, customer, or security claims were added. Product screenshots are copied unchanged from the fork's verification captures. No application source, product logo, or user home was modified.
